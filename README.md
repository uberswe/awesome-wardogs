# Awesome WARDOGS [![Awesome](https://awesome.re/badge.svg)](https://awesome.re) [![Link check](https://github.com/uberswe/awesome-wardogs/actions/workflows/link-check.yml/badge.svg)](https://github.com/uberswe/awesome-wardogs/actions/workflows/link-check.yml)

> A curated list of official channels, community tools, wikis, guides, creators, servers, and reference material for WARDOGS.

WARDOGS is a 100-player, three-faction tactical shooter built on Unreal Engine 5 by [BULKHEAD](https://bulkhead.com/) and published by [Team17](https://www.team17.com/). It entered Steam Early Access on 10 September 2026 (Steam App ID 1867240). The main mode, King of the Hill, descends from Sa-Matra's Arma 3 mod of the same name, and the original mod authors have worked with BULKHEAD since the start of the project.

## Servers and hosting

Community server hosting is whitelist only. BULKHEAD announced on 7 September 2026 that dedicated servers are available through two approved partners, QONZER and BisectHosting, with 60, 80, and 100 player options. The server code is private, so no other host can sell WARDOGS servers. BisectHosting notes that a 100-player server puts three to four times the CPU and network load of a standard 32-player FPS server.

## System requirements

From the Steam store page. The game uses Easy Anti-Cheat, which runs at the kernel level, and requires an internet connection.

| | Minimum | Recommended |
| --- | --- | --- |
| OS | Windows 10 64-bit | Windows 11 64-bit |
| CPU | Intel Core i5-8600 or AMD Ryzen 5 3500 | Intel Core i7-12700K or AMD Ryzen 7 5700X |
| RAM | 16 GB | 16 GB |
| GPU | GeForce GTX 1660 or Radeon RX 590 | GeForce RTX 3070 or Radeon RX 6700 XT |
| Storage | 50 GB | 50 GB |
| Target | 1080p Low at 60 fps, upscaled | 1440p Medium at 70+ fps native, or 4K Medium at 60+ fps upscaled |
